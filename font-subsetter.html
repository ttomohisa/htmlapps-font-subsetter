使い方と注意事項

基本操作

  1. TTF / OTF / WOFF / WOFF2をドロップするか「フォントを選択」から追加します。
  2. 追加したフォントの形式・ファミリー・スタイル・ウェイトなどを確認します。
  3. 「出力」で対象フォントを選び、ファミリー名・ウェイト・スタイルを確認してまとめてWOFF2を生成します。生成後は各フォントをブラウザで再読込し、比較プレビューを確認してからCSSまたはWebfont ZIPを保存できます。

プライバシー

読み込んだフォントはブラウザ内で処理します。このアプリから外部サーバーへ送信しません。

注意事項

  • 1ファイル100 MB、最大12ファイル、合計300 MBまでです。
  • v1.0.2では、複数WOFF2の一括生成、@font-face CSS・unicode-range・demo.html・manifest.jsonを含むWebfont ZIP書き出しまで、完全ローカル処理の一連の流れとして利用できます。
  • 生成後は@font-face CSSをコピーするか、fonts/*.woff2・fonts.css・demo.html・manifest.jsonをまとめたZIPを保存できます。ZIPに元フォントや入力文章は含めません。
  • 文字収集はTXT / MD / CSV / JSON / YAML / HTML / CSS / JS / TS / XML / SVGに対応します。Shift_JISは自動判定しません。
  • 文字プリセットは作業開始用の文字セットです。常用漢字は2,136字を収録していますが、人名・地名・異体字・表外漢字など日本語のすべてを含むものではありません。
  • 「フォントの文字対応」で、不足文字とUnicodeコードポイントを確認できます。
  • 「文字対応レポートをコピー」で、現在の必要文字数・フォント名・状態・対応数・不足数と、各フォント最大500件の不足Unicodeラベルをコピーできます。全件数と省略を明記し、確認できない文字対応は不明とします。入力文章やフォントデータは含めません。クリップボードの内容を共有する前に確認してください。
  • 出力前にOS/2 fsTypeを確認します。No subsetting / Bitmap embedding onlyは生成を停止し、Restricted Licenseは明示的な権利・許可の確認が必要です。fsTypeだけでWebフォント利用の許諾は判断しません。
  • 大きなフォントを多数読み込むと、端末のメモリ状況によって処理が遅くなる場合があります。

必要なコードは単一HTMLに内包され、ローカルファイルとして直接開いて利用できます。
